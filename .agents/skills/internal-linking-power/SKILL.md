# Internal Linking Power Matrix

Equips Antigravity with link equity distribution strategies to pass PageRank to core conversion pages and establish unbreakable topical authority.

## 1. Hub-and-Spoke Architecture
- **Root Pillar (Hub):** `/` (Homepage) and `/open-source` (Tools Hub).
- **Spoke Nodes:** Specific tools (`/open-source/seo-spider`, `/open-source/kdenlive`, etc.) and capability pillars (`/voice-ai`, `/desktop-os`, `/pricing`).
- **Reciprocal Breadcrumbs:** Every spoke page links back to the hub via Breadcrumbs and bottom CTA links ("← Back to all open source software").

## 2. Anchor Text Optimization Rules
- Avoid generic anchor text like "click here", "read more", or raw URLs.
- Use keyword-rich, intent-defining anchor text matching the target URL's primary keyword (e.g. "Download Shotcut 4K Video Editor", "Lifetime Access Licence").
